# Модуль quickmenu — «Быстрые ссылки»

Меню, как Win+X в Windows: Win+X или правый щелчок по знаку Sedmio на
панели. Пункты: «Параметры», диспетчер задач, терминал, «Выполнить»,
свернуть все окна, выход и выключение. Стрелки, Enter, Esc.

- Без модуля Win+X и правый щелчок по знаку ничего не делают («Параметры»
  по Win+X открываются, только если оболочка не запущена).
- Команды: `quickshell ipc -p /usr/share/sedmio/shell call quickmenu toggle|open|close`.
