# Модуль notifications — «Уведомления»

Сервер уведомлений системы: всплывающие карточки справа сверху (обычные
уходят через 6 секунд в центр, срочные висят, пока их не закроют, — и
поверх окна во весь экран), центр уведомлений (Win+N, колокольчик на
панели — точка значит «есть новые»), плитка «Не беспокоить» в Пуске.

- Без модуля уведомления программ не показываются вовсе (программы
  отправляют их в пустоту). Ход копирования файлов виден всё равно.
- «Не беспокоить»: карточки не всплывают, кроме срочных; уведомления
  копятся в центре. Состояние — `~/.local/state/sedmio/notifications.json`.
  Средняя кнопка мыши по колокольчику переключает его.
- Команды: `quickshell ipc -p /usr/share/sedmio/shell call notifications toggle|open|close|clear` (clear — закрыть
  все).
- Выключение и включение перезапускают оболочку (сервер уведомлений
  иначе не освобождает имя на шине) — окна программ при этом живут.
- Уведомление не пришло: включён ли модуль (`sedmio-modules`), не стоит
  ли «Не беспокоить»; проверить — `notify-send Проверка Текст`.
