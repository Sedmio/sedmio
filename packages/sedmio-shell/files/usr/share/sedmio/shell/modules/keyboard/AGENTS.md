# Модуль keyboard — «Раскладка клавиатуры»

Кнопка на панели: ENG, РУС (другие — кодом раскладки). Щелчок или колесо —
следующая/предыдущая раскладка. Видна, только если раскладок больше одной.

- Без модуля раскладки переключаются как прежде (Alt+Shift, Win+Пробел),
  просто без кнопки.
- Какие раскладки и клавиши переключения — «Параметры» → «Клавиатура»
  (`~/.config/kxkbrc`). Свою подпись раскладки (`DisplayNames` в
  kxkbrc) кнопка показывает вместо ENG/РУС.
- Клавиши переключения без просьбы пользователя не менять.
