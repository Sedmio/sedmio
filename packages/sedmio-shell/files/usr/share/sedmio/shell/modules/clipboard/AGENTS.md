# Модуль clipboard — «Буфер обмена»

Win+V — история скопированного (текст, картинки, файлы) с поиском.
Enter или щелчок кладёт запись в буфер и возвращает фокус программе —
остаётся нажать Ctrl+V. Звёздочка — запись не удаляется «Очистить».
Delete (при пустом поиске) — удалить запись. Скопированное остаётся в
буфере и после закрытия программы, из которой копировали.

- История — `~/.local/share/quickshell/clipboard`, 50 записей без
  звёздочки. Пароли из менеджеров паролей (с пометкой
  `x-kde-passwordManagerHint`) не запоминаются.
- Без модуля копирование и вставка обычные, без истории; история при
  этом не пишется вовсе.
- Команды: `quickshell ipc -p /usr/share/sedmio/shell call clipboard toggle|open|close`.
- Выключение перезапускает оболочку — окна программ живут.
