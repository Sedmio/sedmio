# Модуль brightness — «Яркость»

Кнопка яркости экранов на панели; видна, если яркость можно менять.
Щелчок — ползунки яркости.

- Клавиши яркости работают и без модуля; плашку при нажатии рисует
  модуль `osd`.
- Ночная подсветка — «Параметры» → «Экран».
- Открыть командой: `quickshell ipc -p /usr/share/sedmio/shell call control openSection brightness`.
