# Модуль snap — «Привязка окон»

Как в Windows 11: тянешь окно за заголовок к верхнему краю посередине —
раскрывается полоска схем (половины, 2/3 + 1/3, три колонки, четверти…),
отпустил над частью схемы — окно встаёт туда. Потом на свободных местах
миниатюры остальных окон: щелчок — окно встаёт туда, Esc — не надо.
Потянул окно с места — вернулся прежний размер.

- Это скрипт KWin `sedmio-snap`; модуль включает и выключает его.
  Без модуля остаётся обычное прилипание KWin к краям (верх — развернуть,
  бока — половина).
- Клавиши окон (Win+стрелки) — отдельно, скрипт `sedmio-windowkeys`, не
  этот модуль.
