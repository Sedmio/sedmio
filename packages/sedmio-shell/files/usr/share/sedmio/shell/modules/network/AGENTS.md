# Модуль network — «Сеть»

Значок подключения на панели; щелчок — раздел «Сеть» центра управления
(проводная сеть, Wi‑Fi, пароль прямо в строке).

- Без модуля сеть работает (NetworkManager), просто без значка.
  Настройки сети — «Параметры» → «Сеть», из терминала — `nmcli`.
- Открыть раздел командой: `quickshell ipc -p /usr/share/sedmio/shell call control openSection network`.
