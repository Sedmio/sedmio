# Модуль clock — «Часы»

Время и дата на панели, щелчок — календарь.

- Часовой пояс и автоматическое время — «Параметры» → «Дата и время»
  (после смены пояса оболочка перезапускается сама).
- Открыть календарь командой: `quickshell ipc -p /usr/share/sedmio/shell call control openSection calendar`.
