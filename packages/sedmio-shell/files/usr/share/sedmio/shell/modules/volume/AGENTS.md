# Модуль volume — «Громкость»

Громкость на панели: колесо — громче/тише (с плашкой модуля `osd`),
щелчок — звук и микрофон: устройства вывода и ввода, их громкость.

- Звук — PipeWire. Без модуля клавиши громкости работают.
  Устройства по умолчанию — «Параметры» → «Звук», из терминала — `wpctl`.
- Открыть командой: `quickshell ipc -p /usr/share/sedmio/shell call control openSection sound`.
