# Модуль battery — «Батарея»

Заряд на панели (мало заряда — подсвечен), щелчок — заряд и режим
питания. На компьютере без батареи не виден.

- Данные — UPower, режим питания — power-profiles-daemon. Настройки питания и сна — «Параметры» → «Питание» (`powerdevilrc`).
- Открыть командой: `quickshell ipc -p /usr/share/sedmio/shell call control openSection battery`.
