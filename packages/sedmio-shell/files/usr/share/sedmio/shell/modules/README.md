# Модули Sedmio

Всё, что можно выключить, — модуль: папка `<имя>/` здесь, в
`/usr/share/sedmio/shell/modules`. Модуль может поставить любой пакет:
положить сюда свою папку. Оболочка найдёт её при следующем перечитывании
(хук pacman `sedmio-shell-reload.hook` срабатывает на любые файлы здесь).

Имя папки — имя модуля: латиница в нижнем регистре, цифры, `_`
(`[a-z][a-z0-9_]*`). Это же имя QML-модуля: `import qs.modules.<имя>`.

Включить, выключить, посмотреть:

```sh
sedmio-modules                # список
sedmio-modules off battery    # выключить
sedmio-modules on battery     # включить
sedmio-modules reset battery  # как по умолчанию
```

То же — «Параметры» → «Модули». Что решил пользователь, лежит в
`~/.config/sedmio/modules` (`<имя>=on|off`); строки нет — как в
`module.json`. Всё включается и выключается на ходу, без перезахода.

## module.json

```json
{
    "name": "Батарея",
    "description": "Заряд на панели, щелчок — заряд и режим питания.",
    "icon": "battery-good",
    "group": "Панель",
    "order": 30,
    "default": true,
    "status": "Button.qml",
    "screen": "Screen.qml",
    "main": "Main.qml",
    "kwinScripts": ["sedmio-snap"]
}
```

| Поле | Что это |
|---|---|
| `name` | Название в «Параметрах». Обязательно. |
| `description` | Одна-две фразы: что делает и что будет без него. |
| `icon` | Значок из темы значков. |
| `group` | Раздел в «Параметрах»: «Панель», «Окна», «Инструменты». |
| `order` | Место в списке и в ряду кнопок по умолчанию: панель 10–99, окна 100–199, инструменты 200–299. |
| `default` | `false` — выключен, пока пользователь не включит. Нет поля — включён. |
| `status` | Кнопка в ряду состояния на панели. |
| `screen` | Часть, которая создаётся на каждом экране. |
| `main` | Одна часть на всю оболочку: службы, команды `IpcHandler`. |
| `panel` | Шторка сверху посередине (как история буфера обмена). Открывает `ShellState.openPanel(экран, "<имя>")`. |
| `panelWidth` | Ширина шторки, по умолчанию 580. |
| `center` | Центр справа сверху (как центр уведомлений). Открывает `ShellState.openCenter(экран)`; центр один — берётся первый включённый модуль с этой частью. |
| `popups` | Всплывающие карточки справа сверху, под карточками операций. Тоже первый включённый модуль. |
| `tile` | Плитка в Пуске, рядом с Bluetooth и режимом питания. |
| `osd` | Всплывающий индикатор (громкость, яркость) снизу посередине; первый включённый модуль. |
| `menu` | Меню у знака Sedmio (Meta+X, правый клик по знаку). Открывает `ShellState.openQuickMenu(экран)`; первый включённый модуль. |
| `restartOnDisable` | `true` — модуль останавливается только вместе с оболочкой (движок в C++ живёт до конца процесса: буфер обмена, сервер уведомлений): выключение перезапускает её. |
| `kwinScripts` | Скрипты KWin (Id из их `metadata.json`), которые включаются и выключаются вместе с модулем. |

Модулю не обязательно что-то из этого иметь: модуль из одного скрипта
KWin — это `module.json` с `kwinScripts`.

## Части

Части грузит `ModulePart` оболочки. Модуль выключили — его части
уничтожаются, включили — создаются заново. Часть с ошибкой просто не
загружается (сообщение в журнале оболочки), остальная оболочка работает.

- **`status`** — корень `BarButton`. Оболочка передаёт `size`,
  `screenName`, `tooltip` (а часам верхней панели — ещё `wide`). Кнопка,
  которой нечего показать, ставит `visible: false` и места не занимает.
- **`screen`** — получает `screen` (экран, `ShellScreen`). Корень —
  `PanelWindow` (у него `screen` уже есть) или `Scope` с
  `property var screen`.
- **`main`** — ничего не получает. Корень — `Scope`.
- **`panel`** — получает `open` и `maxHeight`; отдаёт `wantedHeight`
  (нужная высота) и сигнал `closeRequested(bool restoreFocus)`. Корень —
  `Item`, его размер задаёт шторка. Пока шторка закрыта, часть остаётся
  загруженной.
- **`center`** — так же, как `panel`: `open`, `maxHeight` → `wantedHeight`,
  `closeRequested(bool)`. Ширина — 400 минус поля.
- **`popups`** — получает `urgentOnly` (`true` — только срочные: они же
  поверх окна во весь экран); отдаёт `count`, сколько карточек сейчас.
  Ширину задаёт оболочка, высота — своя (`implicitHeight`).
- **`tile`** — корень `QuickTile`. Ничего не получает.
- **`osd`** — получает `screenName`; отдаёт `shown` (показать сейчас на
  этом экране) и `wantedWidth`. Высота — 54, подложку рисует оболочка.
  Показать индикатор из другого модуля — `ShellState.osdRequested(вид,
  значок, проценты, максимум, подпись)`: так модули не зависят друг от друга.
- **`menu`** — получает `open` и `screenName`; размер свой
  (`implicitWidth`, `implicitHeight`), сигнал `closeRequested(bool)`.
  Корень — `Item`; рамку карточки рисует сама часть.

В файлах модуля видно всё из оболочки (`import qs`: `ShellState`,
`BarButton`, `SText`…), соседние файлы модуля и его синглтоны
(`pragma Singleton`) — так же, как в корне оболочки. Состояние, общее
для частей модуля, — синглтон в папке модуля (как
`screenshot/ScreenshotState.qml`).

Оболочка не следит за файлами сама: после правки в работающей системе —
`/usr/lib/sedmio/shell-reload` (от root) или перезапуск оболочки.

## Чего пока нет

Служб systemd в модуле (`units`): появятся вместе с первым модулем,
которому они нужны.
