# Модули Sedmio

Всё, без чего можно обойтись, в Sedmio — модуль: папка
`/usr/share/sedmio/shell/modules/<имя>/` с `module.json`. Модуль
включается и выключается на ходу, без перезахода; выключенный не
работает вовсе (не занимает память, не держит клавиши).

## Посмотреть, включить, выключить

```sh
sedmio-modules                 # список: включён ли, имя, название
sedmio-modules info clipboard  # что делает
sedmio-modules off clipboard   # выключить
sedmio-modules on clipboard    # включить
sedmio-modules reset clipboard # как по умолчанию
```

То же — «Параметры» → «Модули» (`sedmio-preferences modules`).
Включать и выключать только так, а не правкой файлов руками:
`sedmio-modules` заодно переключает скрипты KWin модуля и, если нужно,
перезапускает оболочку (буфер обмена и уведомления останавливаются
только вместе с ней — окна при этом не закрываются). Выбор пользователя
лежит в `~/.config/sedmio/modules` (`имя=on|off`, только отличия от
умолчания).

## Что каждый делает

Про каждый модуль — его `AGENTS.md` в папке модуля: что делает, что
будет без него, клавиши, команды, файлы, частые вопросы. Перед советом
про модуль прочитай его:

```sh
cat /usr/share/sedmio/shell/modules/<имя>/AGENTS.md
```

Сейчас: `keyboard` (раскладка на панели), `network` (сеть), `battery`,
`brightness`, `volume`, `clock` (часы и календарь), `notifications`
(уведомления, Win+N), `snap` (привязка окон), `screenshot` («Ножницы»,
PrtSc), `clipboard` (история буфера, Win+V), `quickmenu` (меню Win+X),
`osd` (плашки громкости и яркости). Модули ставят и другие пакеты —
полный список даёт `sedmio-modules`.

## Модуль не работает

1. `sedmio-modules` — включён ли.
2. Ошибки — `journalctl --user -u sedmio-shell -b | grep -i <имя>`.
   Модуль с ошибкой просто не загружается, остальная оболочка работает.
3. Команды модуля (`quickshell ipc … call <имя> …`) есть, только пока он
   включён: у выключенного их нет, и ошибка вызова — это нормально.

## Свой модуль

Модуль может поставить любой пакет: папка в
`/usr/share/sedmio/shell/modules/` (QML на Quickshell, `import qs` даёт
всё из оболочки, цвета — `import Sedmio.Style`, `Theme.*`). Формат
`module.json` и что получает каждая часть — в
`/usr/share/sedmio/shell/modules/README.md`, прочитай его целиком.
Класть свою папку туда руками нельзя — её не знает pacman; правильно —
маленький пакет (PKGBUILD, который кладёт папку), тогда хук pacman сам
перечитает оболочку. Пока пробуешь — после правки
`sudo /usr/lib/sedmio/shell-reload`.
