# Sedmio — правила для нейронок

Sedmio — личный дистрибутив на Arch Linux для двух машин автора: окна,
клавиатура и буфер обмена ведут себя как в Windows, вид — свой. Окна
ведёт KWin (плавающие окна — главная черта, Hyprland не берём), всё
видимое заменено своим: оболочка на Quickshell, «Параметры», «Файлы»,
«Программы», «Ножницы», вход, блокировка, тема. Почему так, а не иначе, —
[docs/decisions.md](docs/decisions.md): прежде чем менять устройство
части, прочитай её раздел.

## Главный принцип

Ничего не правим руками в системе. Любая настройка — файл в одном из
пакетов `packages/`: тогда система собирается с нуля, обе машины
получают изменение обычным `pacman -Syu`, а обновления Arch его не
затирают. Задачу решаем на самом простом уровне, где она решается:
настройки по умолчанию (`/etc/xdg`) → выбор пакетов → свой QML → патч
исходников (только если выше не вышло).

## Где что

```
packages/<пакет>/     PKGBUILD + files/ (как в системе) или app/ (исходники)
  sedmio-shell/         оболочка: панель, рамка, обои, модули (Quickshell)
  sedmio-theme/         темы (Sedmio.Style), рамки окон KWin, символы Lucide
  sedmio-settings/      настройки по умолчанию (/etc/xdg, клавиши, kconf_update)
  sedmio-session/       сеанс: запуск KWin и служб, заставка
  sedmio-preferences/   «Параметры»
  sedmio-files/         «Файлы» и окно выбора файла для всех программ
  sedmio-store/         «Программы»: Arch, Flathub, AUR, AppImage
  sedmio-screenshot/    «Ножницы»: снимок у KWin и редактор
  sedmio-tasks/         диспетчер задач
  sedmio-base/          метапакет: состав системы
  quickshell/, calamares/, plasma-*, …  свои сборки чужих проектов с патчами
iso/                  дополнения к профилю archiso
scripts/              сборка, выпуск, виртуалка
docs/                 решения (decisions.md), как в Windows, разработка
```

## Как работать

- Пользователю пиши по-русски, коротко. Интерфейс Sedmio только на
  русском. Комментарии в коде и сообщения коммитов в этом репозитории
  тоже на русском — пиши так же: зачем, а не что.
- Делай то, что просили. Новые функции и «заодно улучшу» — не делать, а
  предложить. Раскладку и клавиши языка без просьбы не трогать.
- Если есть путь проще или надёжнее, скажи об этом один раз до работы.
- Принятое решение (почему так, что отвергли) — в `docs/decisions.md`,
  в раздел этой части. Устройство модуля — в его README.
- Git: никаких массовых откатов (`checkout -- .`, `restore .`,
  `reset --hard`, `clean`, `stash` без путей) — в дереве бывают чужие
  незакоммиченные правки. Откатывать только свой файл и только после
  `git diff` его. Слитую в main ветку сразу удалять.
- Память хозяина не резиновая: виртуалка 4 ГБ, сборка не больше 8
  потоков, сборка и виртуалка никогда не одновременно. Не хватит — oomd
  закроет целые группы программ, и твою тоже.

## Изменение → система

1. Правка в `packages/<пакет>/` и `pkgrel` +1 в его PKGBUILD (без этого
   до машин не дойдёт, `release-repo.sh` откажется выкладывать).
2. Проверка в виртуалке (навык `sedmio-vm`): своя машина — рабочая, на
   ней не проверяют.
3. Слить в main, собрать и выпустить в `[sedmio]` — только когда
   пользователь скажет (навык `sedmio-packages`).

## Навыки

Подробности по частям — в `.agents/skills/<навык>/SKILL.md` (для Claude
Code та же папка видна как `.claude/skills`). Читай нужный перед работой
с этой частью:

| Навык | Когда |
|---|---|
| `sedmio-packages` | PKGBUILD, сборка, выпуск в [sedmio], ISO |
| `sedmio-vm` | любая проверка: виртуалка, команды в ней, мышь и снимки экрана |
| `sedmio-shell` | оболочка на Quickshell и её модули |
| `sedmio-theme` | цвета и темы, значки-символы, рамки и заголовки окон |
| `sedmio-apps` | свои программы на Qt/QML: «Параметры», «Файлы», «Ножницы»… |
| `sedmio-kde` | KWin и его скрипты, клавиши, kconf_update, порталы, службы systemd |
