# Программы на Qt/QML

Каждая программа — компилируемый пакет: `app/` (C++ + `app/qml/`),
CMake, `qt_add_qml_module`. Вид — Sedmio.Style (навык `sedmio-theme`).

## Как устроена программа

- `main()` (`main.cpp`; у «Ножниц» — `editor.cpp`): `setApplicationName`, `setApplicationDisplayName`
  (по-русски, это имя окна), `setDesktopFileName` (= app_id окна и имя
  .desktop), `QQuickStyle::setStyle("Basic")`, `IconProvider` для
  `image://icon/<имя>` (значки темы в QML), `engine.loadFromModule(…)`.
- Логика — C++-классы с `QML_ELEMENT`/`QML_SINGLETON`, вид — QML. Тяжёлое
  (сеть, файлы, D-Bus) — в C++, не в JS.
- **`QApplication`, а не `QGuiApplication`, если есть FileDialog.** Тема
  KDE отдаёт выбор файла порталу (окно Sedmio из `sedmio-files
  --portal`) только программам на виджетах; иначе Qt рисует запасное
  окно, наполовину по-английски. Для этого — `Qt6::Widgets` в CMake.
- Одно окно на сеанс: имя на шине (`registerOnBus`), второй запуск
  передаёт аргументы первому и выходит (так «Параметры», «Программы»,
  диспетчер задач).
- Свой заголовок окна: `WindowControls` + `WindowDragArea` из
  Sedmio.Style и app_id в `ownheader.h` (навык `sedmio-theme`).
- `.desktop` — в `app/`, ставится CMake'ом; служебное окно (редактор
  снимков) — `NoDisplay=true`.

## Общие элементы

`SText` (Onest с осью wght — `weight:`, а не `font.weight`), `SIcon`
(`symbolic: true` — символ Lucide), `SButton` — копии в каждой программе
(у программ разные пакеты: сломанное обновление одной не задевает
другую); `SSwitch`, `SSlider`, `SField` — пока только в «Параметрах» и
оболочке. Источник — `sedmio-preferences/app/qml`. Копии есть ещё в
оболочке, окнах паролей (`…/sedmio/agents`), входе (`login-ui`) и
установщике. Меняя оформление элемента, меняй все копии
(`find packages -name SText.qml -not -path '*/src/*'`).

## Тексты

Только русский, коротко, без лишних пояснений — пусть объясняет
компоновка. Кнопки — глаголом («Сохранить», «Открыть папку»). Ошибка —
что случилось и что сделать, без кодов. Опасное действие —
подтверждение и цвет `terracotta`.

## Быстрая проверка без пакета

На хосте собрать в свою папку и запустить без экрана — видно ошибки
загрузки QML:

```sh
cmake -S packages/<пакет>/app -B /tmp/<пакет>-build -G Ninja && ninja -C /tmp/<пакет>-build -j8
QT_QPA_PLATFORM=offscreen /tmp/<пакет>-build/<программа> … # смотреть предупреждения
```

Поведение и вид — только в ВМ (навык `sedmio-vm`). Программу, которой
нужны переменные сеанса (окно выбора файла), запускать в ВМ через
`systemd-run --user`, иначе увидишь окно KDE вместо окна Sedmio.

## Ловушки

- Qt 6.12: у Item FINAL-свойства `left`/`top` — свои так не называть.
- Состояние для отмены и «есть несохранённое» — неизменяемые снимки:
  каждая правка создаёт новый массив/объект, «изменено» — сравнение
  ссылок с сохранённым (так в редакторе снимков). Правка на месте
  (`items.push`) привязки не будит.
- `grabToImage` снимает элемент в его собственном размере — для
  экспорта картинки в полном разрешении снимать немасштабированный
  элемент, а масштаб (`scale`) держать у родителя.
- Внешнюю программу (wl-copy, xdg-open) — `QProcess` с аргументами
  списком, не строкой через shell.
