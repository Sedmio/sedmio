# Sedmio Linux

Личный дистрибутив на основе **Arch Linux + KDE Plasma** для двух машин автора.
Цель: система, которая по ощущениям работы с окнами, клавиатурой и буфером
обмена ведёт себя как Windows, но остаётся Linux.

- Интерфейс только на русском, раскладки `us` + `ru`.
- Плавающие окна, поведение как в Windows (см. [docs/windows-feel.md](docs/windows-feel.md)).
- Ядро `linux-cachyos` (основное) + `linux-lts` (запасное).
- Пакеты CachyOS, собранные под Zen 4 (`znver4`).
- Видеокарты: NVIDIA (open-драйвер) + встроенная AMD Radeon.

Все принятые решения и причины: [docs/decisions.md](docs/decisions.md).

## Главный принцип

Ничего не правим руками в системе. Любая настройка — это файл в одном из пакетов
`packages/`. Тогда система воспроизводится с нуля, обе машины получают изменения
через обычный `pacman -Syu`, а обновления Arch не затирают наши правки.

Каждую задачу решаем на самом простом уровне, где она решается:

1. настройки по умолчанию (`/etc/xdg`, политики приложений);
2. ограничения Kiosk;
3. выбор пакетов (не ставим лишнего);
4. свои виджеты и модули на QML;
5. патчи исходников — только если ничего выше не помогло.

## Структура

```
packages/
  sedmio-settings/       настройки по умолчанию: KWin, раскладки, Firefox, pacman
  sedmio-base/           метапакет: что входит в систему + systemd-пресеты
  sedmio-host-desktop/   ПК: Ryzen 7 7700 + RTX 4060
  sedmio-host-laptop/    ноутбук: Ryzen 7 8xxx + RTX 4060 Laptop (гибридная графика)
  sedmio-branding/       загрузчик, Plymouth, экран входа, обои (пока пусто)
iso/                     наши дополнения к стандартному профилю archiso (releng)
scripts/                 сборка пакетов и ISO
docs/                    спецификация и решения
```

## Сборка

Собирать нужно на Arch (или уже на Sedmio), например в виртуалке.

Один раз на машине сборки:

```bash
sudo pacman -S --needed base-devel archiso git
```

Подключить репозитории CachyOS официальным скриптом CachyOS (он сам определит
поддержку znver4 и пропишет нужные секции в `/etc/pacman.conf`), и включить
`[multilib]` в `/etc/pacman.conf`.

Собрать пакеты в локальный репозиторий `out/repo`:

```bash
./scripts/build-packages.sh
```

Собрать ISO в `out/iso`:

```bash
sudo ./scripts/build-iso.sh
```
