# Решения

Короткий журнал: что решили и почему. Новое решение — новый раздел, старые не
переписываем, а помечаем «заменено».

## 1. Основа: Arch Linux

Свежие пакеты, минимальная база без лишнего, удобная сборка своих пакетов
(PKGBUILD) и ISO (archiso).

## 2. Окружение: KDE Plasma, плавающие окна

- Ближе всего к Windows из коробки: панель задач, меню «Пуск», плавающие окна.
- KWin правильно договаривается с приложениями о заголовках окон
  (`xdg-decoration`), поэтому нет двойных кнопок закрытия, как в Hyprland
  с плагином заголовков.
- Поведение настраивается конфигами и скриптами KWin, интерфейс оболочки
  написан на QML и заменяется частями.
- GNOME отвергнут: плохо поддаётся темам, расширения ломаются при обновлениях.
- Hyprland отвергнут: нет нормальных заголовков окон, API плагинов нестабильно.

## 3. Только для двух своих машин

Не нужно автоопределение чужого железа и защита от чужих сценариев.
Главное: воспроизводимость и синхронность двух машин.

| Машина | Процессор | Графика |
|---|---|---|
| ПК | Ryzen 7 7700 (Zen 4) | RTX 4060 + встроенная Radeon, монитор на NVIDIA |
| Ноутбук | Ryzen 7 8xxx (Zen 4) | RTX 4060 Laptop + Radeon 780M, гибридный режим |

Модель ноутбука и наличие MUX-переключателя ещё не выяснены.

## 4. Ядро: linux-cachyos + linux-lts

- Основное `linux-cachyos`: планировщик BORE, отзывчивость и игры.
- Запасное `linux-lts` из официального Arch, отдельным пунктом загрузки.
  Независимый источник: если CachyOS что-то сломает, система всё равно грузится.
- Своё ядро не собираем: обновления безопасности выходят слишком часто.

## 5. Репозитории CachyOS znver4 выше Arch

Обе машины на Zen 4 с AVX-512, поэтому берём пакеты, собранные под этот
процессор. Репозитории подключаются официальным скриптом CachyOS.

## 6. Графика

- ПК: `linux-cachyos-nvidia-open` (готовый модуль) + `nvidia-open-dkms` для LTS.
- Встроенную Radeon не отключаем: запасной видеовыход, если сломается NVIDIA.
- Ноутбук: экраном управляет Radeon, NVIDIA включается по требованию (PRIME)
  и полностью засыпает, когда не нужна.

## 7. Язык: только русский интерфейс

- Тексты пишем сразу по-русски, без системы переводов.
- Переводы на другие языки не устанавливаем (`NoExtract`).
- Раскладки `us` + `ru`.
- Часовые пояса и зеркала — по всему миру, без привязки к России.

## 8. Пользователь

Пользователь вводит только имя (любое, хоть по-русски). Технический логин
латиницей создаётся автоматически транслитерацией и скрыт в «Дополнительно»:
кириллица в логине и пути `/home` ломает часть программ.

## 9. Установка: Calamares + приложение первого запуска

- Calamares со своими QML-страницами: проверенная разметка диска под капотом.
- Как в Windows: установщик задаёт минимум вопросов, а настройка пользователя
  идёт в отдельном красивом приложении при первом запуске.
